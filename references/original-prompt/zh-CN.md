# Original XXD Shop 007 style brief

根据用户提供的产品图、产品图纸、爆炸图、说明书、结构示意图或文字说明，生成一张电商用途的产品解构信息海报 / 零部件拆分图。

先准确识别产品类型、外观结构、核心组件、内部模块、装配逻辑、上下层级关系、连接方式和主要卖点。若用户提供了已有图纸、结构说明、零部件名称、拆解顺序或功能模块说明，优先严格遵循；若只提供外观图而没有清晰内部结构，不要凭空编造过于复杂的内部组件，只可基于常见结构做合理、克制的示意化拆分，并保持说明性而非伪工程真实性。

如用户提供的术语、材料、模块名称、技术结构或工作原理不明确，先进行可靠资料检索，优先参考品牌官方信息、产品说明书、专业资料或公开可信来源，确认部件名称、功能关系和结构逻辑后，再进行可视化表达。

整体画面采用干净、克制、专业、现代的产品信息图风格。背景保持简洁纯净，可使用浅灰、浅米白、浅暖灰或低饱和纯色背景，避免花哨纹理和复杂场景干扰。

主体产品置于画面中心，采用清晰的爆炸式拆分构图，根据产品结构自动选择最合理的拆分方向：可纵向分层拆解、前后展开、左右拆分、模块悬浮展开或局部剖开显示。各部件之间距离清楚，层级分明，既能看出装配关系，又不会过密或过散。产品外壳、核心模块、功能部件、传感器、芯片、电池、滤芯、镜头、风机、支架、底座或其他关键部分，应按照真实或合理的结构顺序展开。

产品本体与零部件保持高质量3D产品渲染质感或高级产品示意质感，材质、颜色和轮廓清晰真实，保留品牌产品识别度。整体视觉要像“高级电商信息图 + 工业设计展示”的结合，而不是生硬工程制图，也不是廉价科普图。

排版建立明确层级：
顶部可设置小型栏目标题，如“产品解构图鉴”；
主标题为产品名称，大而清晰；
副标题用于说明品类与解构主题；
主体周围使用细线引导、编号、简洁标签、短句式功能说明标注各个零部件；
必要时可加入少量信息卡片，辅助解释局部结构、工作原理、技术亮点、气流路径、光学路径、避障逻辑、传感器作用或模块示意；
底部可加入 3 到 5 个核心卖点图标或简洁短语，总结产品优势。

文字信息应极简、清楚、专业。不要堆满说明书式长文。每个标注尽量短而准，优先说明“这是什么部件”以及“它解决什么问题”。线条、箭头、编号、图标风格统一，细节有秩序，避免杂乱。

构图上保证第一眼先看到产品整体与拆分关系，第二眼看到关键模块，第三眼再阅读标注和卖点。信息层级清晰，不让所有说明同时抢眼。局部信息卡片应作为辅助，不可压过主体产品。

色彩逻辑以产品本身颜色为核心，整体保持中性、理性、科技感或专业感。若某个功能模块需要强调，可使用少量点缀色进行局部高亮，如蓝色、绿色、橙色或紫色，但强调色只能少量使用，避免喧宾夺主。

最终效果应兼具：产品真实感、结构清晰度、信息可读性、商业美感和电商传播效率。适用于电商详情页头图、核心卖点页、产品技术页、品牌宣传图和高端信息海报。

避免：随意杜撰复杂内部结构、部件顺序错误、产品识别度丢失、拆分过乱、标注过多、说明过长、所有文字同等大小、背景抢戏、工程图过硬、廉价信息图风格、装饰化过强、缺乏装配逻辑。
