## 해결하는 문제

디지털 기기와 가전 페이지에는 늘 "속은 이렇게 생겼다" 이미지가 필요합니다. 보통은 너무 딱딱해서 읽히지 않는 엔지니어링 도면이거나, 빛나는 칩을 AI가 흩뿌린, 보기는 좋지만 지어낸 그림입니다.

**Shop 007**은 그 중간의 이미지를 만듭니다. **고급 쇼핑몰 인포그래픽 + 산업 디자인 프레젠테이션.** 제품은 실제 조립 순서대로 분해되고, 가는 선·번호·짧은 라벨이 각 부품이 무엇이고 무엇을 해결하는지 알려 주며, 하단에서 3~5개의 장점으로 마무리합니다.

## 부품 목록은 어디서 오나요

| 내가 주는 것 | 분해 방식 |
|---|---|
| 분해도, 도면, 설명서, 부품 목록 | 그대로 따름. 내 순서, 내 명칭 |
| 모호한 모듈 이름이나 원리 | 먼저 공식·전문 자료로 확인 |
| 외관 사진뿐 | 외피와 보이는 모듈만. 내부는 절제된 스케치로 두고 부품 이름을 지어내지 않음 |

목록과 출처는 작업 폴더의 `facts.md`에 쓰고, 모든 라벨이 그것과 일치합니다. 설명서와 PDF는 읽어서 목록으로 만들 뿐, 참고 이미지로 이미지 모델에 보내지 않습니다.

## 분해 세트

세트를 요청하면(기본 3장) 상세페이지에 쓰는 세 종류의 페이지가 나옵니다.

- **첫 화면:** 제품 전체를 분해해 전체 조립을 보여 줌.
- **핵심 기능 페이지:** 핵심 모듈 하나와 그것이 해결하는 문제.
- **기술 페이지:** 부분 단면과 원리 카드 하나.

각 페이지는 부품 목록 중 자기 몫에만 라벨을 붙이고, 핵심 장점은 첫 화면에만 넣습니다. 내부 정보가 없으면 모듈을 지어내는 대신 페이지 수를 줄입니다.

## 준비할 것

- **상품 이미지**(필수): 제품을 알아볼 수 있게 유지합니다.
- **구조 정보**(권장): "분해도 + 부품 목록"에 가까울수록 정확합니다.
- **사양**(선택): 배터리 시간, 출력, 흡입력, 해상도. 숫자는 내가 준 것만.

## 사용 방법

### 1단계: 설치 (한 번만)

```bash
git clone https://github.com/nevertoday/xxd-shop-007.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-007" ~/.claude/skills/xxd-shop-007
```

Codex 사용자는 같은 폴더를 `~/.codex/skills/xxd-shop-007`에 링크하세요. 설치 후에는 AI 어시스턴트 세션을 다시 시작합니다.

### 2단계: 원하는 것을 평소 말로 말하기

```text
/xxd-shop-007 로봇청소기와 공식 분해도예요. 부품은 상판, 라이다, 메인보드, 배터리, 팬, 사이드 브러시, 메인 브러시, 먼지통. 상세페이지용 분해도를 만들어 줘
/xxd-shop-007 이 전동칫솔은 외관 사진밖에 없어요. 분해도를 만들어 줘
/xxd-shop-007 설명서 PDF 첨부. 3페이지 분해 세트를 만들어 줘
```

외울 플래그는 없습니다. 사이즈나 장수처럼 정하지 않은 것은 한 번에 모아서 묻고, 다음에는 지난 설정을 다시 쓸 수 있습니다.

### 3단계: 그다음에 하는 일

1. 상품 이미지와 설명을 읽고 아직 정해지지 않은 것만 묻습니다. 사이즈는 용도에 맞춰 픽셀 크기와 함께 추천합니다.
2. 먼저 부품 목록을 만들고 모든 행에 출처를 답니다.
3. 세트는 먼저 스토리보드와 첫 화면을 보여 드리고, 확인한 뒤에 나머지를 만듭니다.
4. 사이즈마다 새로 구도를 잡고, 다른 이미지에서 잘라내지 않습니다.
5. 납품 전에 한 장씩 확인합니다. 상품이 바뀌지 않았는지, 철자가 맞는지, 주지 않은 숫자가 있는지. 통과하지 못한 것은 알리고 다시 만듭니다.
6. PNG를 `~/Desktop/xxd/xxd-shop-007/` 아래 새 작업 폴더에 저장하고 경로를 알려 줍니다.

**글자 없이 할 수 있나요?**

할 수 있지만 라벨 없는 분해 렌더가 되어 인포그래픽의 역할을 잃습니다. 먼저 알리고, 확인한 뒤 진행합니다.

**영어 상세페이지도 되나요?**

네. 영어 글자를 요청하면 헤더 바도 영어로 바뀝니다.

**무엇이 필요한가요?**

세 가지입니다. ① Claude Code나 Codex처럼 Skills를 지원하는 AI 어시스턴트. ② 이미지를 생성할 수 있는 모델: 어시스턴트에 내장된 이미지 생성, 또는 Codex에 설정한 모델 제공자로 Responses API를 통해 이미지를 생성하는 것(기본 GPT Image 2). ③ Pillow가 설치된 Python 3.11 이상(`pip install pillow`).

**비용이 드나요? 상업적으로 써도 되나요?**

Skill은 무료로 내려받을 수 있고, 이미지 생성 비용은 본인의 모델 계정에 청구됩니다. 이 프로젝트는 PolyForm Noncommercial 라이선스입니다. 개인 학습·연구·테스트는 괜찮지만, 쇼핑몰 운영, 외주 납품 등 상업적 사용은 먼저 작성자의 서면 허가가 필요합니다. 맨 아래 "라이선스"를 참고하세요.

**이미지는 얼마나 큰가요?**

**이미지 속 글자에 오타가 생기나요?**

AI 이미지는 가끔 철자를 틀리거나 브랜드 이름 옆에 ® 같은 작은 기호를 덧붙입니다. 납품 전에 한 장씩 확대해 확인하고, 통과하지 못하면 다시 만듭니다. 이 페이지의 예시는 모두 그 확인을 통과했습니다.

**가격이나 판매량을 지어내나요?**

아니요. 가격, 사양, 원산지, 판매량, 수상, 인증처럼 사실로 보이는 것은 내가 준 것이나 상품에서 또렷이 읽히는 글자에서만 가져옵니다. 그 밖에는 넣지 않으며 "¥XX" 자리표시도 없습니다.

**상품 여러 개를 한 번에 처리할 수 있나요?**

네. 상품 이미지 폴더를 주세요. 이미지 하나에 상품 하나, 사이즈와 글자는 한 번만 묻고, 한 상품의 사실이나 문구가 다른 상품으로 새지 않습니다.
